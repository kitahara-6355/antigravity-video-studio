# 本編の仕上げ（番組化の3段目）

2026-10-23 に「20250922_久木田ヒロノブ」の v62 から v63 を作った手順。北原さんが見本から形を選んだ。
手順は**ファイルとコマンドだけ**で書いてある。どの AI が動かしても同じ mp4 が出る。

- 費用は0円。Gemini API も AI の画像・音声の生成も使わない（絵は収録のコマ、文字は Google Fonts）
- 本編の絵と字幕は1コマも変えない（完成版の上に重ねるだけ）
- テロップの文言だけは AI が字幕を読んで書く。**本編で言っていることだけ**を書く

## 入力

| もの | 場所 |
|---|---|
| 完成版（目視OK・字幕焼き込み済み） | Drive `40_完成/<収録ID>/`（例 `_v62_ロゴなし.mp4`） |
| 承認済みの字幕 | 同じ所の `.subtitles.json`（テロップの時刻を探す） |
| 投稿パッケージ | `program-package` の出力（チャプターをここから読む） |
| サムネの指定ファイル | `backend/config/thumbnails/<収録ID>.json`（色紙の所と背景の色を使い回す） |
| つないだ raw と lock | 色紙のコマを字幕なしで取るため |

## 手順

### 1. 指定ファイルを書く

`backend/config/episode/<収録ID>.json`（見本 `examples/20250922_久木田ヒロノブ.json`）。時刻はすべて**完成版の時刻**。

| 欄 | 中身 | 決め方 |
|---|---|---|
| `program_opening` | 番組専用 OP（どの回でも同じ）: 番組名・説明2行・場面（`from`/`to`＝その回の完成版の時刻、`raw`・`lock` で字幕の無い raw から取る）・番組名の秒数・音楽 | 場面は各回の笑顔・揮毫など**言葉の要らない絵**。回が増えたら各回から足す。音楽は出所のはっきりした曲だけ（`music.path`・`start`＝曲のどこから・`volume`）。**市販の音源は原盤権の許可が要る**。仮の曲は `provisional: true` にすると、出力の名前に「_仮曲入り」が付く（公開に使わない印）。無いうちは `null` |
| `title` | 番組名・回・肩書き・ゲスト名・聞き手 | 名前は北原さんが決めた表記のまま |
| `opening.cuts` | OP の名場面（2〜3か所・合わせて15秒前後） | 一番強い実績の発言 → 絵で引く場面（揮毫の書き終わり）→ 決めの一言。字幕の出だしと終わりで切る |
| `opening.title_seconds` | OP の最後のタイトルの秒数（3.5） | |
| `chapters_skip` | 見出しを出さない章（エンディング） | **第1章も出す**（本編の頭から） |
| `chapter_seconds` | 章の見出しを出す秒数 | **8秒**（4秒は短すぎると言われた） |
| `name_pops` | `at`・`seconds`・`y`・`right`（右端の x）・`lines`（肩書き）・`name` | 聞き手のあいさつ・ゲストの紹介の所。肩書きは**本編で紹介した言葉どおり**。頭に掛からない壁の所に置く |
| `telops` | `at`（秒）・`head`（言葉）・`body`（説明。改行可） | 知らないと分かりにくい固有名詞・専門語。字幕の言い方から外れない。**他社の画像・ロゴは使わない** |
| `ending` | 秒数（20）・プレゼントの告知・登録の呼びかけ | 締切が決まるまでは `【未定】` と書く（投稿用には書き出さない） |

### 2. 静止画で確かめる

```
python -m backend.program_package.episode SPEC.json --out OUT --cards
```

`OUT` に OP のタイトル・章の見出し・テロップ・ED の png が出る。完成版のコマに重ねて、
人の頭・字幕・絵の外（黒い縁）に掛かっていないかを見る。

### 3. 書き出す

```
python -m backend.program_package.episode SPEC.json --out OUT
```

- 並び: 番組 OP（シーン集＋番組名）→ 今回の名場面 → タイトル → 本編 → ED
- 出るもの: `<収録ID>_<version>.mp4` と `<収録ID>_<version>_チャプター.txt`（OP の分ずらした時刻）
- チャプターが YouTube の決まり（0:00・3つ以上・各10秒以上）に合わなければ止まる
- 42分の本編で約15〜25分（CPU）。**名場面は本編と別の入力として読む**（同じ入力から切ると、
  そこまでの本編のコマを全部メモリに溜めて落ちる。2026-10-23 に一度 SIGKILL になった）

### 4. 確かめて北原さんに渡す

- 長さ = OP + 完成版 + ED になっているか（`ffprobe`）
- OP・章の見出し・テロップ・ED のコマを1枚ずつ出して見る
- 確認用は Drive `40_完成/<収録ID>/` へ（スキル `drive-layout` の `put finished`）。返信にはリンクを貼る
- 概要欄のチャプターは `_チャプター.txt` に差し替える（OP の分ずれる）
- 目視OK のラベルは北原さんが付ける（AI は付けない）
