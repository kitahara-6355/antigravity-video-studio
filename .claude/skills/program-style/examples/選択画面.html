番組の雰囲気えらび

① 方向を1つ選ぶ　② 注文カードで手直しを足す　③「この形で決める」。 どれも絵コンテ（4コマ）と縦の画面の1枚で見比べられます。動画と曲は、決まってから当てます。

① 方向を選ぶ 色・書体・置き方がちがう 16 案。左上から 書き足す途中 → 言葉が出そろう → 番組名が出る途中 → 締め、右の細い1枚は縦の画面（Shorts）

② 注文カード 押すと選ばれます。左が今の案、右が注文を当てた姿。同じ種類（大きく／控えめに など）はどちらか1つ

注文を2つ以上選んだ形は、決めたあと Claude が絵コンテと動画にしてお見せします。

③ ひとこと なくても大丈夫。理由は番組の判断の記録に残し、次の案づくりに使います

「ほかの案も見たい」は、ひとことに見たい方向（例: もっと明るく、筆の勢いを強く）を書いて押すと、Claude が新しい案を作ります。
