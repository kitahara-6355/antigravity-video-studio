# 長尺1本の投稿パッケージを作る（番組化の1段目）

2026-10-22〜23 に「20250922_久木田ヒロノブ」で Claude Code が最後まで作った手順。
番組化はまず Claude Code で作り切り、このスキルにしてから Gemini Spark で再現する（北原さんの方針）。
手順は**ファイルとコマンドだけ**で書いてある。どの AI が動かしても同じものが出るように。

費用は0円。Gemini API も AI 画像生成も使わない（写真はすべて収録のコマ。合成でないので開示ラベルは要らない）。

## 入力

| もの | 場所 |
|---|---|
| 完成動画（目視OK） | Drive `40_完成/<収録ID>/`、ラベル「品質確認」が目視OK のもの |
| 承認済みの字幕 | 完成動画と同じ所の `.subtitles.json` |
| 編集の固定（lock） | 書き出しの時刻 → raw の時刻をたどる区間。例 `r61.lock.json` |
| つないだ raw | lock の `material`（例 `raw4_concat.mp4`）。**字幕の焼き込みが無いのでサムネのコマはここから取る** |

## 手順

### 1. 投稿パッケージを書く（AI が字幕を全文読む）

書くもの: タイトル案3つ・概要欄・チャプター・ゲスト紹介・タグ・投稿前の確認。
見本は `examples/20250922_久木田ヒロノブ_投稿パッケージ_v1.txt`。

- タイトルは「ゲストの一番強い実績」を頭に置く（例「鬼滅の刃」）。3案は切り口を変える
- 概要欄の定型（リンク・SNS）は**【仮】のまま**にする。北原さんが決めるまで埋めない
- チャプターは話題の変わり目。字幕の時刻から取る
- 本編で言っていないことは書かない（社名・作品名は字幕どおり。表記は辞書に従う）

チャプターが YouTube の決まり（0:00 始まり・3つ以上・各10秒以上・増えていく）に合うか:

```
python -m backend.program_package.chapters 投稿パッケージ.txt --duration <動画の秒数>
```

### 2. サムネを組む（構成 P1）

P1（2026-10-23 北原さん決定）: 背景は**収録の壁の薄紫＝美麗書院のテーマカラー**、中央に金縁の色紙、
左に美麗さん・右にゲストの**笑顔**を切り抜いて大きく、下に「赤＋金」の明朝でキャッチ1行、
上に黒箱で肩書き、両端に名前を縦書き。参考にしたのは「プレミアム対談」型のサムネ。

1. 指定ファイルを作る `backend/config/thumbnails/<収録ID>.json`（見本は 20250922_久木田ヒロノブ.json）
   - `text`: 肩書き・キャッチ2つ・左右の名前。**名前は北原さんが決めたまま変えない**
   - `shikishi`: 揮毫の場面で色紙が手で隠れていない時刻と、色紙の所（俯瞰のコマ）
   - `left` / `right`: 切り抜きの候補（本編の時刻）。**表情優先・明るい笑顔**。3秒おきにコマを並べて探し、
     よい所を0.5秒おきに見直して決める
2. フォントを取る（初回だけ。Google Fonts・OFL）

   ```
   python -m backend.program_package.thumbnail --fetch-fonts
   ```

3. 候補を並べて北原さんに選んでもらう

   ```
   python -m backend.program_package.thumbnail SPEC.json --raw RAW.mp4 --out OUT --options
   ```

   `OUT/切り抜き候補.jpg` を返信に添付し、「B3とK1」のように選んでもらう。
4. 選ばれた組み合わせで組む（`chosen` にある組をすべて、または `--pick B3 K1`）

   ```
   python -m backend.program_package.thumbnail SPEC.json --raw RAW.mp4 --out OUT --pick B3 K1
   ```

5. スマホの一覧の大きさ（幅320px）に縮めても文字と表情が読めるかを見る。
   右下は再生時間の表示に隠れるので、大事な字を置かない

### 3. 置く・控える

- 決まったサムネは Drive `40_完成/<収録ID>/` へ（スキル `drive-layout`）:

  ```
  python -m backend.drive_layout put finished <フォルダ> --to <収録ID>
  ```

  仮決定のうちは名前に「仮決定」と入れる（例 `_サムネ_仮決定_P1_薄紫_B3_K1.png`）
- 何を選んだか・誰が決めたかは指定ファイルの `decided` と `chosen` に残す

### 4. Shorts を切り出す（番組化の2段目）

スキル `shorts-cut` に分けた（場面選び・書き出し・確かめ方・北原さんへの見せ方・決まりの経緯）。

### 5. 本編を仕上げる（番組化の3段目）

OP・章の見出し・補足のテロップ・ED を足す手順はスキル `episode-finish` にある。

### 制作の順番と雰囲気えらび（2026-10-25 北原さん）

Shorts を先に投稿用に仕上げる → 番組共通 OP を資産として作る（Shorts としても出せる縦の版も）→ 本編を仕上げる。
番組の雰囲気（OP の現れ方・背景・締め）は、見本を並べて北原さんが選ぶだけで決める。手順はスキル `program-style`。

## 北原さんに決めてもらうこと（AI は決めない）

- タイトル（3案から）・サムネの組み合わせ・出す Shorts とその順番
- 概要欄の定型（リンク・SNS）
- 投稿前の確認: ゲストの公開の了解・プレゼント企画の応募方法と締切・作品名の書き方
- 投稿そのもの（外に出す操作なので AI はしない）
