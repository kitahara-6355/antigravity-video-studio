# Flash タスクディスパッチ ワークフロー v1.0

## 概要
統括チャット（Opus）から Gemini Flash タスクチャットへの指示プロンプトを自動生成し、
結果回収までの一連のフローを標準化するワークフロー。

## 起動条件
- ユーザーが「Flashに指示するプロンプトを作って」「Flash用のタスクを生成して」等と指示した場合
- ユーザーが `/flash-task` コマンドを使用した場合

---

## Step 1: タスク情報の収集

以下の情報を確認・収集する：

1. **タスクの目的**: ユーザーの指示から具体的な作業内容を特定
2. **関連ファイル**: 変更対象・参照対象のファイルパスを特定
3. **前提知識**: VerifiedFacts / TDR から関連情報を抽出
4. **品質ゲート**: タスク完了の検証コマンドを決定

---

## Step 2: 指示プロンプトの生成

以下のテンプレートに沿ってプロンプトを生成し、ユーザーに提示する：

```markdown
# [タスク名] — Gemini Flash タスクチャット指示

## プロジェクト情報
- **パス**: c:\Users\PC_User\Desktop\script\video-automation
- **GEMINI.md**: プロジェクトルートの GEMINI.md を必ず読んで従うこと
- **CLI操作不要**: 外部で心拍プロセス（`tick_loop.py`）が別途稼働しているため、本チャット内でのCLI（`python`コマンド等）による心拍起動や操作は一切不要です。あなたはチャットUI上での自走ループ（`while True`によるAPI連携）に専念してください。

## コンテキスト
[自動挿入: タスクに必要な背景情報、関連する VerifiedFacts、TDR エントリ]

## 自律動作と安全規約（必須）
1. **自己ステータス監視制限（役割誤認防止）**:
   本セッションで監視・表示する進捗ステータスは、プロジェクト全体の統括ではなく、**あなた自身のセッション（`flash_session.json`）の範囲**（バッチ・タスク進行・ハートビート）に厳格に限定してください。あなたが全体統括（Opus）の役割であるとハルシネーションを起こすことを厳禁とします。
2. **待機秒数の動的可変化**:
   サブエージェント完了チェックは通常10〜15秒の短い間隔でポーリングし、API 429（リソース制限）等のエラー発生時は30秒〜300秒のクールダウン（待機秒数の可変化）を動的に制御してください。
3. **自己復旧サイクル**:
   サブエージェントのタイムアウト（900秒）検知とタスク再割り当て、例外発生時の安全な自動ロールバックおよびTDR（技術負債自動解消）の自己復旧サイクルを確実に回してください。
4. **常時タイマー表示義務**:
   タスク処理の待機や合間の回答時には、必ず `schedule` ツールを呼び出して300秒の監視タイマーを設定し、UI上に進捗ステータス（完了数/バッチ状況）とタイマーが常時表示される状態を維持してください。

## タスク
[具体的な作業内容を箇条書きで記述]

## 参照ファイル
[変更対象・参照対象のファイルパスをリスト化]

## 成果物
1. [期待されるコード変更・ファイル生成]
2. **報告レポート**: 重要な判断・指摘のやり取りについて、ユーザー・AI双方の発言原文を引用した記録報告レポートを作成

## 品質ゲート
- `pytest tests/test_fitness_functions.py` → 全PASS必須
- [タスク固有の検証コマンド]

## 完了時の手順
1. 報告レポートを `Human01_Official Artifact/受信トレイ/` にコピーして保存
2. `Human01_Official Artifact` フォルダを推移表管理ルールに従って整理整頓
3. VerifiedFacts に成果を `category=progress` で記録（API経由）
```

---

## Step 3: 結果回収

Flash タスクチャットの完了後、ユーザーが結果を統括チャットにフィードバックする方法：

### 方法 A: 受信トレイ確認（推奨）
```
統括チャットで「受信トレイを確認して」と指示
→ Human01_Official Artifact/受信トレイ/ を読み込み
→ 新着レポートの内容を要約・統合
```

### 方法 B: 引き継ぎプロンプト
```
Flash チャットの最終出力をコピー
→ 統括チャットに貼り付け
→ 「以下、Flashからのフィードバックです。」
```

### 方法 C: VerifiedFacts 確認
```
統括チャットで VerifiedFacts (category=progress) を読み込み
→ Flash が記録した進捗情報を確認
```

## 運用ガイドライン

### Flash に適したタスク
- 大規模 OSS リサーチ
- ドキュメント・レポート生成
- 推移表の更新・整理
- コスト効率重視の定型作業

### サブエージェントに適したタスク（Flash ではなく invoke_subagent を使う）
- コードの実装・テスト
- 品質スコア監査
- コードベース調査
