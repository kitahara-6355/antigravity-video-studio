# 設計ドラフト: ソウル・ナラティブ演出哲学還流エンジン (IMP-SOUL-FEEDBACK)

## 概要
ユーザーの「こだわり（却下理由や手動調整）」から抽出された演出哲学（`evolution_log.json`）を、次回の動画制作時に「おすすめサジェスト項目」として可視化提示する還流エンジンの設計ドラフト。ユーザーが「編集のキモ」を学びながら、ワンクリックで一括適用できるUXを両立させる。

## 1. 演出サジェストカードの生成ロジック
- **入力データ**:
  - `backend/branding/evolution_log.json` 内の `philosophies` (演出哲学) と `decision_insights` (承認・却下履歴)。
  - 今回処理対象となるRAW動画のプロファイル（ジャンル、対談/ソロ、録音環境）。
- **生成処理 (Gemini による推論)**:
  - 過去の「こだわり」や「失敗からの学び」をスキャンし、今回の動画に適用すべき「おすすめの編集項目（BGM音量、テロップサイズ、カットの間隔など）」を3〜5個抽出。
  - 各項目に、ユーザー自身が「編集のキモ」を学べるよう、**【お勧めする演出意図と過去の背景】** を1行で自然言語解説として添える。
    - 例: `[BGM音量の設定: -6dB]`
      *解説*: 前回（5/21）の対談動画で「BGMが大きすぎてトークの主役である声が聞き取りづらい」と却下されたため、今回は声の周波数を邪魔しない -6dB を推奨します。

## 2. ユーザーインターフェース (UI/UX)
- **サジェスト項目リスト (箇条書き＋チェックボックス)**:
  - 提示された項目に対して、適用したくないものはチェックを個別に外すことができる。
- **一括適用 (Apply All) ボタン**:
  - 面倒な設定変更を避けるため、チェックが入っているすべてのサジェスト値を、ワンアクションで今回の編集構成ファイル（`edit_config.json`）に自動マージして適用する。
- **元に戻す (Undo) 機能**:
  - 一括適用後に、瞬時に適用前のデフォルト設定に戻せる Undo ボタンを併設する。

## 3. バックエンド API 仕様
- `GET /api/evolution/suggestions?video_id={id}`
  - 返却値: サジェストの配列。各要素は `id`, `category`, `value`, `title`, `reason` (お勧めする演出意図)。
- `POST /api/evolution/suggestions/apply`
  - パラメータ: `applied_suggestion_ids` (適用するIDのリスト)。
  - 処理内容: 指定された設定値を `edit_config.json` にマージし、適用結果を `evolution_log.json` に「同期適用ログ」として追記する。

### [2026-05-23 17:45] ユーザー合意および仕様決定 (議長合意)
- **演出哲学の還流方針**: アプローチ ②「提案サジェスト型」を採用。
  - AIが自動で前回の哲学を強制適用するのではなく、過去のこだわりから「おすすめサジェスト項目」をリストアップし、解説を添えて提示する。
- **解説（学習）の重視**: 「編集のキモ」をユーザーが学び成長できるよう、サジェスト項目ごとに具体的な演出意図と過去の背景（却下履歴など）を明文化して添える。
- **摩擦のないUX（一括適用）**: 設定作業の手間を省くため、「おすすめ項目の一括適用」ボタンを配置。チェックを入れたサジェスト値をワンタップで `edit_config.json` に反映する。
- **UI/UX画面要件**: サジェストカードはトグル開閉で詳細な解説を読めるようにし、デフォルトではスッキリした項目出しリストと「一括適用」ボタンを表示する。
