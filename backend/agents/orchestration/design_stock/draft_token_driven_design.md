# 設計ドラフト: デザイントークン連携システム (IMP-TOKEN-DESIGN)

## 概要
ビジョンバックログ D-17（デザイントークンがフロントエンド参照ゼロ）を解消し、憲法第17条（デザインシステムプロトコル）の「一貫したデザイントークン適用義務」を果たすため、`branding/design_tokens.json` に定義されたデザインスタイルと、フロントエンド（React/CSS）および動画プレビューのテロップスタイルを同期・連動させるシステムの設計ドラフト。

## 1. デザイントークン連携データフロー

```
    [branding/design_tokens.json]
                  │
        ┌─────────┴─────────┐
        ▼                   ▼
 [バックエンドAPI]    [動画編集・テロップ焼き込み] 
        │            (Pillow/FFmpeg はトークンを参照して描画)
        ▼
[フロントエンド: React] 
   ├── 1. API 経由でデザイントークンをロード
   ├── 2. CSS Variables (`--primary-color` 等) にバインドしてUIスタイルを同期
   └── 3. テーマ選択（ThemeSelector）でのムード切り替えを即時適用
```

---

## 2. コア機能仕様

### ① デザイントークン定義の拡充 (`design_tokens.json`)
*   メインカラー、アクセントカラー、背景色。
*   タイポグラフィ（フォントファミリー、標準サイズ、字幕用セーフガード境界値）。
*   アニメーションイージング・スピード定義。
*   ユーザーがテーマ（例：`calm` (穏やか)、`energetic` (活発) など）を切り替えた際に対応する色・フォント設定のプリセットマッピング。

### ② CSS Variables 同期機構 (`ThemeManager.js`)
*   フロントエンド起動時、およびテーマ切り替え時にバックエンドから `design_tokens.json` をロード。
*   ブラウザの `:root` 要素に対して CSS Variables を動的に設定する。
    *   例: `--color-primary`, `--font-subtitle`, `--spacing-safe-area`
*   これにより、UIダッシュボードの表示色と、動画内で描画されるテロップやロゴのスタイルが完全に同期する。

### ③ 字幕プレビューシミュレータ (`SubtitlePreview`)
*   ユーザーがフロントエンド上で「字幕デザインの微調整」や「テーマ選択」を行った際、サーバー側で動画を生成することなく、ブラウザ上で CSS を用いて「動画上のテロップの見映え」を完全にシミュレートするコンポーネント。
*   `design_tokens.json` のコントラスト比計算アルゴリズム（WCAG 2.1）を JS 上でも再現し、見づらい組み合わせ（例: 黄背景に白文字）をUI上でリアルタイム警告する。

---

## 3. バックエンド API 仕様

*   **`GET /api/branding/tokens`**: 現在のデザイントークン構造（色、フォント、テーマ設定）の取得。
*   **`PUT /api/branding/tokens`**: ユーザーのチャット指示や自動学習に基づいてデザイントークンを更新。
*   **`POST /api/branding/tokens/compile`**: デザイントークンから CSS ファイル（`design_tokens.css`）をビルドしてフロントエンド静的領域に出力する機能（API呼び出しを節約するためのオプション）。
