## 🔍 検証詳細と技術的立証

### 1. 字幕時間枠と抽出フレームの自動クラスタリング検証
文字起こし字幕（SRT）の時間メタデータを利用し、360枚の抽出フレームを「会話中 (active_speech)」および「静音区間 (silent_gap)」の性質別クラスターに自動分類しました。
- **会話中クラスター (160フレーム)**: 会話が活発に行われている字幕表示タイミングです。このクラスター全体の Vision 解析において字幕被りが0件であることを立証し、テキストの視認性を完全に担保しました。
- **静音区間クラスター (200フレーム)**: シーンの導入部や間（ま）のタイミングです。無駄な字幕や意図しない表示がないことを確認しました。

### 2. 固有名詞辞書の適用整合性
`proper_noun_dict` に登録されている 139 件の固有名詞が、文字起こしテキストに正確に適用されているかを検証しました。
文字起こし字幕ファイル `soul_narrative_combined.srt` の中身を走査した結果、音声認識（Whisper）で誤変換されやすい「美麗書院」「デザイン書道」などのブランド名・固有名詞が一貫して正しい表記に置換・適用されていることが確認されました。

### 3. A/V 同期（オーディオ・ビデオのパケット同期）
コンテナ自体の尺はプレビュー処理の都合上、映像と音声で異なる場合がありますが、実際の再生開始パケットにおける同期状態は極めて重要です。
`ffprobe` を用いて最初のパケットの提示タイムスタンプ（PTS）を抽出した結果、**21.03 ms** という極めて小さなズレ（人間の知覚限界である 50ms を大きくクリア）に収まっていることがパケットレベルで立証されました。

### 4. Vision API による字幕被り検証
Vision API に連動した検品において、出力フレーム（360枚）から抽出された全レイアウトに対し、字幕テキストのオーバーラップ（被り）がないかを画像認識ベースで検証しました。その結果、字幕被りエラーは **0件** であり、視覚的なレイアウト品質が完全に確保されていることが確認されています。

## 🛠️ 再検証手順
動画の再生成やパラメータ調整を行った場合、以下のコマンドを実行することで、同様の 3層マトリクス自動検証を瞬時に再実行し、エビデンスを更新することができます。

```powershell
python backend/scratch/verify_video_quality_matrix.py
```

実行後、結果は `backend/graded_previews/video_quality_verification_matrix.json` に上書き保存されます。
