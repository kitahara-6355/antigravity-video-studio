# Creative Asset Library

## フォルダ構造

```
assets/
├── channel_owner/     ← チャンネル主の素材
│   ├── photos/        ← 写真
│   ├── videos/        ← 動画クリップ
│   └── logos/         ← ロゴ
├── guests/            ← ゲストの素材
│   └── [ゲスト名]/
│       ├── profile.json
│       ├── photos/
│       └── works/
├── templates/         ← テンプレート
│   ├── opening.mp4
│   └── ending.mp4
└── brand/             ← ブランド素材
    ├── fonts/
    └── music/
```

## 使い方

1. 素材をフォルダにドロップ
2. システムが自動でインデックス化
3. 生成時に自動参照
