# BGM ディレクトリ

このディレクトリにBGMファイル（`.mp3` / `.wav`）を配置すると、
パイプラインの最終レンダリング時に自動的にBGMダッキング・ミキシングが適用されます。

## 使い方

1. `default_bgm.mp3` というファイル名でBGMを配置
2. パイプラインが自動的にBGMを検出し、サイドチェイン圧縮でダッキング処理を実行

## テンプレート連携

テンプレートの `branding.bgm_path` に任意のBGMパスを設定することで、
テンプレートごとに異なるBGMを使用できます。

## 注意事項

- BGMのサンプルレートは 44.1kHz / 48kHz を推奨
- 著作権フリーの音源を使用してください
