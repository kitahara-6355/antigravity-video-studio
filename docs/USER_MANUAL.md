## 1. はじめに





### Antigravity とは





動画編集の「重力」から解放し、**AIと共に創造性を最大化する**統合スタジオです。





### 2つのユーザーロール





Antigravityには**2種類のユーザー**がいます。それぞれの役割と責任は明確に分かれています。





#### 🎤 チャンネル主 (Owner)





| 項目 | 内容 |


|:---|:---|


| **誰？** | YouTubeチャンネルの配信者・クリエイター |


| **やること** | 直感で「いい」「ダメ」を判断する |


| **必要スキル** | 日本語が話せる + ボタンを押せる |


| **触る画面** | 素材選択、クイックレビュー、SmartCut、段階的レビュー |


| **触らない画面** | サーバー設定、API監視、CI/CD |





#### 🛠️ 管理者 (Admin)





| 項目 | 内容 |


|:---|:---|


| **誰？** | 技術担当者・AIオペレーター |


| **やること** | パイプライン管理、品質監視、システム運用 |


| **必要スキル** | コマンドライン操作 + API理解 |


| **触る画面** | API監視ダッシュボード、CI/CD、パイプライン設定 |


| **触らない画面** | 演出判断、コンテンツ承認 |





#### 🤖 AI (Antigravity)





| 項目 | 内容 |


|:---|:---|


| **役割** | 提案・実行・記録 |


| **動作原則** | Ownerの判断を最優先。品質90点以上を自動保証 |

#### CTR予測の詳細





**CTR（Click Through Rate）とは**: YouTubeでサムネイルが表示された回数のうち、実際にクリックされた割合です。





| CTR値 | 評価 | 意味 |


|:---|:---|:---|


| 1-2% | 低い | 改善が必要 |


| 2-3% | 標準的 | 業界平均レベル |


| 4-5% | 良好 | 上位パフォーマンス |


| 6%以上 | 優秀 | トップクリエイター級 |





**予測の仕組み**: AIが以下の要素を分析してCTRを予測します


- **色彩コントラスト**: 目を引く色使いか


- **テキスト可読性**: 文字が読みやすいか


- **顔の表情**: 感情表現が適切か


- **構図**: 視線誘導が効果的か





**サムネイル生成方式**: Imagen 4モデルで画像を新規生成します。RAW動画のスクリーンショットは使用しません。

### 5.8 エコシステム連携と独自の成功パターンの資産化（成長の共有） ✨NEW

多くのチャンネル主が本システムを使用する中で生まれた「新しい成功パターン」や「成長ログルート」を資産化し、エコシステム全体へメジャーアップデートを通じて還元するための仕組みです。

#### 100人100通りの成功アセット化と動的ペルソナ登録

* **動的成功スキーマ (Dynamic Success Schema)**
  ユーザーごとの編集スタイルや演出（テロップ配色、カットテンポ、BGM比率）の組み合わせと、実際のYouTube Analyticsの実績を解析し、独自の「成功パターン」としてローカルに自動アセットパッケージ化します。これにより、誰でも自分専用の「勝ちパターン」をシステム内に保存・再利用できます。
* **カスタムペルソナ設定**
  ユーザーが独自の「目標（ゴール）」や「仮想ペルソナ（例：こだわり派女性YouTuber、視聴者対話重視のビジネス解説者など）」を登録できます。AI評議会は、そのペルソナの観点で動画を監査し、感性に寄り添ったフィードバックを提供します。

#### 成長ログルートのローカル資産化

* **成長ログルートのエクスポート**
  YouTube Analyticsでのパフォーマンス（CTR、平均視聴維持率、高評価率など）が良好だった動画の編集パラメータ軌跡（成長ログルート）を、ローカルで「成功アセット」としてエクスポートできます。
* **知的財産の保護**
  エクスポートされた成功パターンは、他のプリセットと干渉しない独立したファイルとして安全に管理され、チャンネル主個人の知的財産（資産）として永続的に保護されます。

#### 匿名パブリック還元とメジャーアップデート還流

* **匿名パブリック還元（オプトイン）**
  利用者は、自身のローカル成功アセットや成長ログパターンを, 中央のメタデータストア（Ecosystem Registry）に匿名で共有（アップストリーム）することができます。この機能は完全なオプトイン方式であり、公開されていない動画の生データや機密情報は自動的にマスクされ、外部に送信されることはありません。
* **メジャーアップデートによる「集合知の還流」**
  中央に匿名で集められた膨大な成功パラメータ群を、AIの「戦略分析エージェント（YouTuberStrategist）」が定期的に解析・分類。新たに発見された優れたパターンは、メジャーアップデートのタイミングで全利用者のローカルシステムへ「新規編集テンプレート」として配信・還流されます。一人の成功が、エコシステム全体の動画品質の底上げに直結します。

#### YouTube＋主要SNSのクロスメディア多角的分析

* **YouTube＋SNSクロスメディア統合監査**
  動画単体のCTRや視聴維持率だけでなく、チャンネル主が運営する主要SNS（X、Instagram、TikTok、Threads等）のアカウントと連携し、投稿テキスト、インプレッション、エンゲージメント率、およびフォロワー数の推移をクロスメディアで統合分析します。
* **クロスメディア相関分析による成功要因の可視化**
  SNS上での告知タイミングや発信内容の反応と、YouTube動画の再生数初速や視聴傾向の相関関係（Cross-Media Correlation）をAIが自動解析し、外部流入の最大化要因やブランド認知プロセスを明らかにします。
* **動的スタイル遷移と連携戦略のアシスト**
  現在のチャンネルおよびSNSの運営スタイルがトレンドやアルゴリズムに適合しているかを常時監視し、「SNS上でのビジネス関心層の増加に合わせ、YouTubeでもデータ分析型テンプレートへのリベースを推奨する」といった動的なクロスメディア運営戦略を `Soul Passport` を介してサジェストします。

## 9. トラブルシューティング





### よくある問題と解決策





| 問題 | 原因 | 解決策 |


|:---|:---|:---|


| 画面が真っ白 | フロントエンド未起動 | `npm run dev` を実行 |


| AI分析が動かない | バックエンド未起動 | `uvicorn main:app` を実行 |


| 「認証エラー」 | APIキー未設定 | `.env` に `GOOGLE_API_KEY` を設定 |


| 動画読み込みが遅い | ファイルサイズ大 | パス指定方式を使用 |


| プレビューが表示されない | ブラウザ互換性 | Chromeを使用 |





### 大容量ファイルの扱い





| ファイルサイズ | 推奨方式 | 処理方法 |


|:---|:---|:---|


| 100MB未満 | ドラッグ＆ドロップ | 通常アップロード |


| 100MB以上 | ファイルパスを入力 | ローカル参照 |


| 500MB以上 | パス指定 + 分割処理 | 自動チャンク処理 |





#### 分割処理の詳細





500MB以上の大容量ファイルは、システムが自動的に以下の分割処理を行います：





**処理フロー**:


```


① 動画を10分単位のチャンクに分割


② 各チャンクを並列で処理（AI分析・字幕生成）


③ 処理結果を時系列で結合


④ 統合された結果を表示


```





**分割処理のメリット**:


- メモリ不足を防止


- タイムアウトエラーを回避


- 処理速度の向上（並列処理）





**注意事項**:


- 分割境界でシーンが途切れる可能性があるため、最終確認を推奨


- 分割処理中は進捗バーで状況を確認可能


- 処理完了後、チャンク境界は自動で調整される





### ログの確認





```bash


# バックエンドログ


tail -f backend/logs/app.log





# フロントエンドログ


ブラウザの開発者ツール → Console


```

## 11. 企画ラボ（タイトル先行制作） ✨NEW





### 11.1 概要





MrBeast流の「タイトル先行制作」を実現。企画段階でタイトルとサムネイルのCTRをAIが予測し、「GO/RECONSIDER」の判定を行います。





### 11.2 使い方





1. 設定画面→「💡 企画ラボ」タブを開く


2. チャンネル名とタイトル案を入力


3. 「CTR予測」ボタンを押す


4. AIが5案のCTR予測とGO/RECONSIDER判定を返す





| 表示 | 意味 |


|:---|:---|


| 🟢 GO | CTR予測が基準以上—撮影開始推奨 |


| 🟡 RECONSIDER | CTR予測が低—タイトルの再検討を推奨 |





> **効果**: 撮影前に「そもそもクリックされないタイトル」を排除できるため、制作コストを最適化できます。

## 12. 運用監視ダッシュボード ✨NEW





### 12.1 概要





テレビ局放送技術部水準のリアルタイム監視。システム状態・API使用量・パイプライン状況を一目で把握できます。





### 12.2 開き方





1. 設定画面→「📊 運用監視」タブを開く





### 12.3 表示内容





| セクション | 内容 |


|:---|:---|


| システム状態 | バックエンド・フロントエンド・FFmpeg・GPUの稼働状況 |


| API使用量 | Gemini APIの日次/分次クォータ残量 |


| パイプライン | 実行中・完了・失敗の履歴 |


| ディスク | Vault領域の使用率・残容量 |





### 12.4 ヘルスチェックAPI ✨NEW





システムの死活監視用エンドポイント。外部監視ツール（Uptime Kuma等）との連搼にも対応。





| API | 説明 |


|:---|:---|


| `GET /health` | 簡易ヘルスチェック（healthy/degraded/unhealthy） |


| `GET /health/deep` | 詳細チェック（FFmpeg/GPU/Gemini/Whisper/ディスク） |





> **TV局水準**: 障害発生時に5分以内で原因特定できる設計。JSON構造化ログと併用することで迅速なデバッグが可能です。
