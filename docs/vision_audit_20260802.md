**ビジョン実現度 71.2%（変化なし）。** ただし**表示されていた値は 60% だった。**

これはスコアが上がったのではなく、**サマリー欄が 2026-05-18 の再計測時に更新し忘れられていた**
だけである。`axis_scores` の加重平均も、`score_history` の最終記録も、`trinity_roadmap` も

「E2E が動くこと」ではないからである（採点方針: コード存在=最大20% / E2E動作=50%以上 /
本番動画確認=100%）。実測なしにスコアを動かさない、という原則を明示的に守った。

### カバレッジは比較できない（D-22）

前回値 **77% は branch coverage**、今回測れたのは **line 75.4%** である。
CI が `--cov-branch` を採っていないため、同じ指標で測れない。
**指標が違うものを並べて「下がった」と読むのは誤り**なのでスコアは据え置き、
バックログ D-22 に起票した。`ci.yml` に1オプション足せば以後は比較できる。

なお**テスト件数は 2,064（2026-04-28）→ 9,244** に増え、失敗0である。
これは公開リポジトリ再作成後の CI 実測で、権威ある数字。

### フロントのビルド可否を初めて測った

フロントには CI が無く、「バックエンドが全部グリーン」でもビルド可否は未検証だった。
**今回初めて実測し、成功を確認した。** lint は 46 errors 6 warnings で main と同数。

## 課金により据え置いた2軸

`pipeline_e2e`（重み20）と `ui_api_connection`（重み15）は、実測にパイプラインの実走が要る。
このリポジトリでは **Gemini API**（本番38モジュールが使用）と `text-embedding-004` が
従量課金なので、**1回走らせるだけで請求が発生する。**

憲法第3条により計画段階で予算を諮り、**ユーザー判断で据え置きとなった**（2026-08-02）。
値は 2026-05-18 の実測のままである。

加えて **`backend/.env` が存在せず API キーが未設定**のため、現状そもそも実行できない
（公開リポジトリ再作成時に持ち込まなかったもの。D-20）。

重み35、全体の35%が「2.5ヶ月前の値」で据え置かれている。**この不確かさは
スコアの数字には表れない**ので、ここに明記しておく。
