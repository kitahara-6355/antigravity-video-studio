### (3) API キーの点検

**旧ツリーに個人アカウントのキーが実在する**（`video-automation/backend/.env`・2026-04-01）。
個人アカウントなら**無料枠が使える**ので、R1 の「1本あたりの実費を知る」目的には

ユーザーが `antigravity-video-studio/backend/.env` に `GOOGLE_API_KEY` を置いたら:


| `🚫 quota_exhausted` | 枠はある・使い切り | 時間を置いて再実行 |

### (4) 動画を1本通す ← **R1 の本丸**

```bash
python -m backend.revenue.artifact_gate --semantics   # 何を見るゲートか
python -m backend.revenue.artifact_gate --gate        # いまは正しく FAIL する
```

**2回に分ける。** 過去の成功率が 12.5% なので、**1回目からゲートの体裁を
整えようとすると、パイプラインの不具合と記録コードの不具合を同時に相手にする**ことになる。

| | やること | 取れるもの |
|---|---|---|
| **1回目** | 既知の通った経路（`scratch/run_e2e_real_raw.py` の系統）で**素直に通す** | **mp4（R1-C1）**・所要時間・落ちる箇所 |
| **2回目** | `RunRecorder` を被せて走らせる | 実行記録（**R1-C4/C5/C6**）・原価（**C2**） |

無料枠なら2回走らせても ¥0。**まず短い素材（10〜30秒）で1回目**を通し、
本番 RAW（17分55秒）は経路が確定してから。

**`logo_overlay.py` の ffmpeg タイムアウトを最初に確認する** — 過去に本番尺で
顕在化して 60秒 → 1800秒 に直した箇所。公開版に同じ修正が入っているとは限らない。

2回目に被せる書き方:

**各工程を `RunRecorder.stage()` で包んでから走らせる。** 包まないと記録が残らず、
成果物ゲートが `model_not_recorded` で FAIL する（それが仕様）。

```python
from backend.revenue.run_record import RunRecorder

rec = RunRecorder(inputs={"source": "..."})
with rec.stage("transcribe", model="local:whisper", stage_input={...}):
    ...
with rec.stage("telop", task="telop_suggestion", stage_input={...}):
    ...
    rec.artifact("output/final/demo.mp4")
rec.finish()
```

- ローカル処理は `model="local:ffmpeg"` の形で**モデルを使わないことも宣言する**
- `stage_input` を渡さないと、失敗時に**再開できない**とゲートが言う（fail-closed）
- 実測モデルは `cost_guard` 台帳から自動で拾われ、宣言と食い違えば `model_mismatch` に残る

**まず短い素材（10〜30秒）で通す。** 長尺は原価と時間が読めてから。

## 4. 未決事項（ユーザー判断待ち・こちらから催促しない）

### (a) キー構成 — **`--probe` の結果で決まる**

P3（採用済み）は「上3段は無料枠の Flash、pro だけ課金」だが、
**課金を有効にすると同じプロジェクトの無料枠が消える**（二次情報）。
1プロジェクト1キーでは P3 が成立しない可能性がある。

- 無料枠が使えた → **1キーのまま。実装変更なし**
- 使えなかった → **2キー構成**（無料 Flash 用 / 課金 Pro 用）。
  `gemini_client_factory` は `GOOGLE_API_KEY` を1本しか読まないので、
  **段（tier）ごとにキーを選ぶ実装**が要る。`model_policy` に寄せれば工程側は無変更

### (b) Drive の扱い — **直結しない方針でユーザーと合意（2026-08-16）**

Google ドライブ デスクトップで共有ドライブをマウントし、パイプラインは
**ローカルパスとして読む**。OAuth もサービスアカウントも要らない。
`scripts/google_oauth_login.py` と `backend/services/workspace_sync.py` は当面使わない。

⚠ ただし `workspace_sync.py` が API 経由を選んだ理由が記録されている:
**ファイル名と中身が食い違った実例がある**（`20251010_..._インタビュー.mp4` の中身が別収録）。
マウントするとファイル ID を失うので、**内容ハッシュで同一性を見る**代替が要る。

### (c) GCP/GWS 上での実行 — **将来課題（ユーザー判断・2026-08-16）**

無料枠は「どこで動かすか」と無関係。クラウドに出すと**いま無料の ffmpeg/Whisper が有料になる**。
本数が増えて手元が律速になってから考える。

### (d) Spend Cap

AI Studio の Spend タブ →「Monthly spend cap」がプロジェクト単位の月額上限。
設定できたら `.claude/budget.json` の `spend_cap_usd` / `spend_cap_project` を埋める。
未設定だと `python -m backend.cost_guard --status` が警告する。
