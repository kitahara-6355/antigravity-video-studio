## 6. P5 の顛末（記録）

**10回破られ、10回塞いだ。** 破られ方の変遷が資産なので残す。

| 回 | 破られ方 | 学び |
|---|---|---|
| 1 | 相対パス／`'/'+'api'`／変数に束ね直した扉の関数／除外ディレクトリ追加 | 誤検出を消すために禁止を狭めない |
| 2 | `/health`／複数行 import／再輸出シム／**テストが CI で走っていない** | testpaths に登録されているか確かめる |
| 3 | `frontend/src` の外／`.mts`／`//host/api/x` | 走査範囲を借りると借りた側の限界が穴になる |
| 4 | NUL を1文字混ぜると走査から外れる | **中身で読む/読まないを決めない** |
| 5 | `src/components/build/`／symlink／`.png?raw`+`new Function` | 除外は相対パスの完全一致で |
| 6 | `import.meta.glob({as:'raw'})`／素の `Function(` | **綴りの列挙で塞ごうとするな** |
| 7 | マジックバイト8バイトの後ろに JS | **中身そのものをハッシュで固定する** |
| 8 | `package-lock.json` が走査からも固定からも落ちる | 条件を2か所に分けない。**差集合で決める** |
| 9 | frontend の外の JS を素の相対 import／`dist` に `git add -f` | 走査した場所から**外を名指しさせない** |
| 10 | `'/../x'`／`../`／`file:../x`／**alias を計算で組む** | 判定を1本に。最後の1件は**字句では原理的に閉じない**→ limits |
