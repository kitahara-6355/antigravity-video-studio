## 5. 数え方の規則（人の感覚で決めない）

- **本番＝本線（`agents.pipeline_coordinator`）と API（`main`）から import を辿れるもの。**
  相対 import・`from pkg import sub`・`import a.b.c` の親も辿る
- **コードと文書を分ける。** docstring / 行頭 `#` のコメント / `if __name__ == "__main__":` の中は文書
- **設定データは値だけを数える。** 値がまるごとモデル ID（`^(models/)?gemini-2\.5[\w.-]*$`）のものが依存。
  **キーは依存ではない**（`deprecated` / `fallback_chain` / 価格表のキーは「訂正される入力」や
  「旧モデルの単価」であって、使うモデルではない）。**散文の中の言及も依存ではない**
- **設定データは import を辿れないので全部を本番として扱う**（fail-closed）。
  読めない JSON も安全側に倒す
