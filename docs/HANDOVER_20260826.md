## 2. このセッションで確定した最重要事実

### **(A) モデル解決器が2つあって、全工程で食い違う** ← 最大の発見

```

director      model_policy=gemini-3.7-flash   model_governance=premium    ★
quality_gate  model_policy=gemini-3.7-flash   model_governance=premium    ★
```

`backend/model_config.json` の `task_mapping` は**段の名前**（`"standard"` / `"premium"`）を持つ。
`model_policy.resolve()` はこれを段として解決するが、
**`model_governance._resolve_model()` は生のまま返す。**
返った値がモデル ID として API に渡り:

```
404 NOT_FOUND: models/standard is not found for API version v1beta
```

| 解決器 | 使用箇所 |
|---|---|
| ❌ `model_governance._resolve_model` | `youtube_opt_worker` / `quality_gate_ai` / `model_registry` / `youtube_optimizer_plugin` / `opening_ending_plugin` / `adk_agent_template` / **`model_governance.call()` 自身** |
| ✅ `model_policy.resolve` | `soul_feedback_engine` / `run_record` / `verify_account` |

**製品の LLM 呼び出しは `soul_feedback` を除いてほぼ全部 404 している。**
「21工程登録されているのに実走で1回しか呼ばれない」の原因はこれ。
**安く直る。直せば AI 能力がまとめて点灯する**（R1.5-C2）。
