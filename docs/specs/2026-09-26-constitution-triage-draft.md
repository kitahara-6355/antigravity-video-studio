# 憲法（PROJECT_CONSTITUTION.md・1,120行）の第1回仕分け案 — M1g（R2 ゲート）で承認を取る

**提案であって決定ではない。** 憲法はビジョンそのものなので、改訂はユーザーの領分（CLAUDE.md 憲法第1条・「触ってはいけないもの」）。
基準は計画書 §3 の V1 — **収益化（G1〜G4）に効くか**。仕分けは4種:

| 印 | 意味 | 扱い |
|---|---|---|
| **必達** | 100% の判定に入れる。met か、フェーズの条件に紐づける | 未達なら M のどこかで作る |
| **後送** | 削らないが、G2 以降（M5g）で再判定 | いまは作らない・壊さない |
| **改訂** | 現実（R2 の実装・CLAUDE.md の憲法）と矛盾するので文言を直す | 改訂案を併記 |
| **削除** | 実態が無く、収益化にも効かない | 削る（履歴には残る） |
