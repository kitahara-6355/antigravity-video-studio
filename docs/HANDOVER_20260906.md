## 8. 踏んだ罠

- **CI の `cancel-in-progress`。** `testpaths 外の退行検知` は**1時間50分前後**。
  PR イベントでは `cancel-in-progress: true` なので、**run が完走するまで push しない**
- **「呼び出し口の閉包ゲート」はコメントも検査する。** 説明コメントに `api` で始まる
  スラッシュ区切りの経路を書くと落ちる。**呼び出し口の名前**（`getSettings` 等）で書く
- **`.jsx` は CRLF のものと LF のものが混在**（`ProductionWizard.jsx` は LF、`SoulPassport.jsx` は CRLF）。
  編集前に必ずバイト列で数え、**元の改行を保つ**
- **`Path.write_text` は Windows で LF を CRLF に変える。** `write_bytes` を使う
- **Bash のヒアドキュメントはバックスラッシュを壊す。** 複雑な置換は**スクリプトをファイルに書いて実行する**
- **Workflow のスクリプトはテンプレートリテラル内にバックティックを書けない。** 配列 + `join('\n')` で組む
- **テスト実行が状態ファイルを書き換える**（`assets/asset_index.json` / `backend/branding/*.json` /
  `backend/quality_score_history.jsonl` / `backend/usage_tracker/usage_data.json` /
  `backend/data/youtube_analytics/performance_cache.json` / `backend/agents/memory/Director.json` /
  `backend/tests/e2e_results.json` / `archives/analytics/history.jsonl` / `src/scenes_data.json` /
  `backend/data/reviews/`）。**`git add` の前に1件ずつ見て戻す**
- **同名テストの重複。** `backend/tests/` と `tests/` に同名ファイルがある。
  **片方だけ直すと CI の「testpaths 外」で落ちる**（20周目に実際に踏んだ）
- **`l` を変数名にすると ruff E741 でラチェットが落ちる**
- **バックグラウンド実行は10分で SIGTERM される。** 全件テストは分割するか、
  影響範囲を絞って1ファイルずつ回す（`cc_affected_run.py` の作り方は §10）

  ただし**範囲の判断（対象か `limits` か）はユーザーに上げる**。
  `limits` への宣言は**正典の終了条件を狭める行為**なので憲法第1条の領域
- 指摘が出たら、**対応してから**次の周を回す
- テストが3回連続で FAIL したら止めて報告する
- 有料利用は予算の範囲内なら都度確認不要（憲法第3条）
- **C4・C6 が揃ったら R1.5 のフェーズ終了。** 正典2箇所に met を立て、CI 緑を確認したうえで、
