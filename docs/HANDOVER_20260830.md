## 6. 踏んだ罠（実際にやらかしたもの）

- **CI の `cancel-in-progress`。** `testpaths 外の退行検知` は228ファイル×2版で**1時間超**。
  PR イベントでは `cancel-in-progress: true` なので、**1周ごとに push すると毎回打ち切られる**。
  実際 `908eeff` の run は 228 中 36 で cancelled になり、**「緑」を6周ぶん名乗れなかった**。
  **run が完走するまで push しない**
- **gate-verifier と作業ツリーを共有している。** 検証中は**私がファイルを触らない**。
  一度 `git checkout --` で相手の変異を壊した可能性がある
- **テスト実行が状態ファイルを書き換える**（`assets/asset_index.json` /
  `backend/branding/design_tokens_history.json` / `evolution_log.json` / `user_model.json` /
  `usage_data.json` / `quality_score_history.jsonl` / `src/scenes_data.json` /
  `archives/analytics/history.jsonl` / `backend/data/reviews/`）。**`git add -A` の前に1件ずつ見る**
- **同名テストの重複。** `backend/tests/` と `tests/` に同名ファイルがある
  （`test_quality_gate_agent.py` / `test_mcp_server.py` / `test_self_review_engine.py` 等）。
  **片方だけ直すと CI の「testpaths 外」で落ちる**
- **`@patch` は下から順に引数へ対応する。** 上に足したら引数は**末尾**
- **ソース文字列の grep をテストにしない。** コメントに文字列が残るだけで通る（2回やった）
- **実ファイル依存のテストは空振りする。** 中身が空だと `if 行:` で黙って素通り（1回やった）
- **手元（Windows）で緑なのに CI（Linux）で赤**になることがある
  （`os.access` の挙動差 / `sys.modules` に残った MagicMock による汚染）
- **UI-API ラチェットは行番号ずれで落ちる。** 中身を変えていないなら
  `python -m backend.ux_verification.ui_api_ratchet --redeclare "理由"` で受理させる
- **Bash のヒアドキュメントはバックスラッシュを壊す。** Python スクリプト経由で置換する
